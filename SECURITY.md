# Security policy

We take the security of Epixo and the people who use it seriously.

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Tell us what you found, how to reproduce it and what impact it could have.

| Step | Timeline |
|---|---|
| We confirm we received your report | within 3 working days |
| We share our assessment and plan | within 14 days |
| We release a fix for serious issues | as soon as it is safe to do so |

We are glad to credit you once the fix is released.

## Scope

- The Epixo website and its API
- The Epixo editor, including exported code and Live Mirror
- The Epixo runtime in `runtime/`

Out of scope: denial of service by heavy traffic, social engineering, and problems in third-party services.

## Supported versions

Security fixes go to the latest release, which is the version running on the live site.
